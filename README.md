# Painel de agenda de eventos

Criei um painel para organizar encomendas e eventos recebidos pelo WhatsApp. A agenda reúne as informações de cada pedido para que a equipe possa consultar o que foi combinado e o que precisa preparar.

## Como funciona

1. O cliente envia a solicitação pelo WhatsApp.
2. A equipe registra o pedido na agenda com os dados necessários para a preparação.
3. A operação consulta o registro para acompanhar os compromissos do dia.

## Exemplo com dados fictícios

Uma cliente solicita um coffee break para 25 pessoas às 9h. A equipe registra a data, o horário, a quantidade de pessoas e os itens combinados. No dia do evento, a operação consulta a agenda para conferir o pedido antes da preparação.

## Minha contribuição

Usei minha experiência como líder de atendimento para definir o que a equipe precisava acompanhar, orientar a criação do painel com IA e testar o resultado na rotina. O painel nasceu de uma necessidade prática da operação: transformar o que foi combinado com o cliente em um registro que a equipe pudesse consultar na hora de preparar o pedido.
