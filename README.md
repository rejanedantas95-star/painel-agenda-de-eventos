# Painel de agenda de eventos

Criei um painel para organizar encomendas e eventos recebidos pelo WhatsApp. O painel transforma o que foi combinado no atendimento em um registro que a equipe de operação pode consultar na hora de preparar cada pedido.

## O problema que motivou o projeto

O WhatsApp é o ponto de contato com o cliente. Para preparar um evento, a operação precisa consultar dados como data, horário, quantidade de pessoas e itens combinados. A agenda reúne essas informações em um registro de trabalho, acessível à equipe que vai preparar o pedido.

## Do atendimento à operação

| Etapa | O que acontece | Para que serve |
| --- | --- | --- |
| Atendimento | O cliente envia a solicitação pelo WhatsApp e a equipe alinha os detalhes. | Entender o que o cliente precisa e confirmar o combinado. |
| Registro | A equipe lança os dados do pedido na agenda. | Deixar as informações de preparação disponíveis em um só lugar. |
| Conferência | A operação consulta a agenda e abre o registro do evento. | Conferir o horário e os itens antes de preparar o pedido. |

## Exemplo de uso

*Demonstração com dados fictícios.*

Uma cliente pede um coffee break para 25 pessoas, às 9h. Depois de alinhar o pedido pelo WhatsApp, o atendimento registra a data, o horário, o número de pessoas e o cardápio combinado. Na agenda do dia, a operação localiza o evento e abre o registro para conferir o que precisa preparar.

| Campo | Valor de exemplo |
| --- | --- |
| Tipo de evento | Coffee break |
| Data e horário | 10/12/2026, às 9h |
| Número de pessoas | 25 |
| Itens combinados | Café, suco, mini sanduíches e bolo |

## Uso na rotina

A agenda é usada para acompanhar encomendas e eventos recebidos pelo WhatsApp. O atendimento registra o combinado e a operação tem um ponto de consulta para preparar os pedidos do dia.
